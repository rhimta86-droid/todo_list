# Todo List

A simple browser-based todo list app.

## Usage

1. Open `index.html` in your browser.
2. Add tasks using the input field.
3. Mark tasks complete, delete items, or clear completed tasks.
4. Tasks are saved in browser storage so they persist after refresh.

## Files

- `index.html` – app structure
- `styles.css` – app styling
- `script.js` – todo list behavior and persistence
